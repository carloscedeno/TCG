# Daily Log — 2026-11-08

## Objetivos del Día
1. Diseñar e implementar la ingesta de **Riftbound TCG (`RFB`)** en Geekorium (DEV).
2. Definir e implementar el modelo arquitectónico **SortSwift-First** para Riftbound (metadatos, imágenes, precios e inventario físico provistos integralmente por SortSwift).
3. Eliminar el acoplamiento y hardcodeo de MTG / CardKingdom en la interfaz frontend mediante un registro dinámico declarativo Omni-TCG.

## Tareas Completadas

### 1. Registro Declarativo Omni-TCG (`frontend/src/config/tcgRegistry.ts`)
* Creado el módulo centralizador `TCG_REGISTRY` con tipado estricto `TCGConfig`.
* Definición de marketplaces externos dinámicos:
  - MTG -> `CardKingdom` (`getCardKingdomUrl`).
  - RFB, PKM, OPC, DGM, FAB, LOR, YGO -> `TCGplayer` (`https://www.tcgplayer.com/product/${externalId}`).
  - GND -> Oculto (sin mercado secundario externo configurado).
* Formatos de legalidad dinámicos por juego (oculta la sección si el juego no posee formatos tradicionales de MTG).
* Atributos polimórficos de combate dinámicos (`might`, `cost`, `domains` para RFB; `hp`, `ap`, `cost_level` para Gundam).

### 2. Refactorización de Componentes Frontend
* **`CardModal.tsx`**:
  - Reemplazado el bloque fijo de CardKingdom por `externalMarket` dinámico.
  - Ocultada la grilla fija de legalidad de Magic si el juego no tiene formatos.
  - Agregado renderizado de badges de atributos específicos (`Might`, `Cost`, `Domains`).
* **`CardDetail.tsx`**:
  - Eliminados los condicionales hardcodeados `details?.game !== 'GND'`.
  - Integrado `tcgRegistry` para legalidad y botones de mercado exterior.
* **`FiltersPanel.tsx`**:
  - Colores/dominios y tipos de carta ahora se obtienen directamente de `getTcgConfig(selectedGame)`.
* **`imageOptimization.ts`**:
  - Añadido soporte nativo para URLs de DigitalOcean Spaces de SortSwift CDN.
* **`api.ts`**:
  - Reemplazado el mapeo `game_id === 17 ? 'GND' : 'MTG'` por el mapeo canónico completo de la tabla `games`.
  - Inyección de `tcg_specific_attributes` y `external_id` (TCGplayer product ID) en las respuestas de detalle.
* Compilación y build de producción validada: `tsc -b && vite build` exitoso en 5.73s.

### 3. Data Loader SortSwift-First (`scripts/sync/riftbound/sync_sortswift_riftbound.py`)
* Conexión con el cliente oficial de SortSwift (`SortSwiftClient`).
* Ingesta de sets canónicos de Riftbound:
  - *Set 1: Origins* (`OGN`, ID 30973)
  - *Set 2: Spiritforged* (`SPF`, ID 30974)
  - *Set 3: Unleashed* (`UNL`, ID 30975)
* Inserción en base de datos DEV cumpliendo el trigger estricto `trg_validate_tcg_attributes`:
